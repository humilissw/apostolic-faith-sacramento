---
name: File Structure
description: Frontend key files and directory organization
type: reference
---

- `app/` - Next.js App Router pages (contact, doctrines, media, sermon)
- `components/` - Shared React components
- `components/ui/` - Base UI primitives (Radix-based)
- `hooks/` - Custom React hooks
- `lib/` - Utility libraries
- `public/` - Static assets
